Вариант 1: api.devops.local, порт 8001, STUDENT=Abalaev.
Исходный коммит шаблона: 3ee6c4bfda24df8cb4d61f8a27031813b3238338.

| № | Исходный файл и строка | Дефект | Последствие | Исправление |
|---|---|---|---|---|
| 1 | Dockerfile:1 | python:latest | Повторная сборка может использовать другую основную версию Python, другой размер и состав ОС; на стенде требуется лишняя загрузка. | python:3.12-slim из ПР7. |
| 2 | Dockerfile:5–6 | COPY . . до установки зависимостей | Изменение app.py сбрасывает кэш pip install и приводит к повторной загрузке и установке зависимостей. | Сначала COPY requirements.txt и pip install, затем COPY app.py. |
| 3 | Dockerfile:5, отсутствует .dockerignore | В контекст попадают .env и каталог .git | Секрет может попасть в слой образа, а история Git увеличивает контекст и также содержит старый пароль. | Исключения .env, .env.*, .git/; копирование только нужных файлов. |
| 4 | .env:1, отсутствует .gitignore | Файл с паролем отслеживается Git | Пароль доступен всем читателям репозитория и остаётся в истории после удаления файла. | Удалить .env из текущей версии, добавить .gitignore и .env.example; на сервере сгенерировать новый пароль. |
| 5 | Dockerfile:1–9, отсутствует USER | Gunicorn запускается от root | Уязвимость приложения даёт злоумышленнику права root внутри контейнера и возможность изменять доступные этому пользователю файлы. | Создать пользователя app и добавить USER app. |
| 6 | Dockerfile:9 | CMD в shell-форме | PID 1 становится /bin/sh, обработка и передача сигналов завершения зависят от оболочки; остановка может ждать SIGKILL. | CMD в exec-форме, Gunicorn непосредственно PID 1. |
| 7 | Dockerfile:9 | Прослушивание 127.0.0.1 внутри контейнера | Перенаправление Docker приходит на сетевой интерфейс контейнера, а не на его loopback, поэтому опубликованный порт не обслуживается. | Внутри контейнера 0.0.0.0:8001, на Ubuntu публикация только 127.0.0.1:8001. |
| 8 | Dockerfile:8–9 | Порт 8000 вместо 8001 | Перенаправление и Nginx варианта 1 обращались бы к порту, который приложение не слушает. | EXPOSE 8001 и --bind 0.0.0.0:8001. |

Базовый образ закреплён digest cb33f7f771ecec2ef1225cf39b159591a040391bd73e4c01f00fdfc4c47611d2 из журнала сборки ПР7. Это сохраняет именно загруженную тогда версию, а не изменившееся содержимое тега.

Логика app.py и состав requirements.txt сохраняются. Единственное изменение app.py — первая строка с комментарием, требуемая для проверки кэша.

Пароль из шаблона считается раскрытым. Удаление .env новым коммитом не очищает историю. Опубликованный main сохраняет исходную историю по заданию; действующий пароль генерируется заново только на VM и нигде не публикуется. Очистка общей истории, если она понадобится, требует согласования со всеми участниками и повторной синхронизации их копий.
